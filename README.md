# AWO Driving School

Responsive AWO Driving School marketing site built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

The booking form validates an enquiry and opens a pre-filled email draft; the visitor must review and send it in their email app. Replace the contact details in `src/data/site.ts`, `src/components/layout/Header.tsx`, `src/components/layout/Footer.tsx`, and `src/pages/BookingPage.tsx` if they change.
